# OmniHawk WSL

Windows + WSL2/Ubuntu x86-64 development and testing environment for the OmniHawk drone project.

This repository is intentionally separate from `omnihawk-jetson`. It must not contain Jetson-specific ARM64/JetPack installation instructions presented as PC instructions.

## Purpose

Use this repository to determine which portable OmniHawk components can be developed or tested on the Windows PC through WSL2, while keeping the Jetson Orin Nano deployment clean and independent.

## Status

Environment setup and compatibility testing in progress. Components will only be marked supported after they are verified for the WSL/x86-64 environment.
